## Known issues and blockers

- npm is forced offline with outbound proxy restrictions. Cached core dependencies and installed local third-party packages are used only to enable local validation. No other application's source or configuration was copied.
- Docker CLI exists but engine is unavailable; starting Docker Desktop cannot write its external log directory. Native MySQL fallback is used.
- The native Node test runner's default child-process isolation produced `spawn EPERM`; running the same scenarios without subprocess isolation works.
- A generated dependency-copy folder remains inside ignored `node_modules`; automatic approval review rejected the cleanup action. It is not application source or served content. Recreate dependencies with a clean registry-backed installation when permitted.
- No visual screenshot or rendered responsive review was possible. Passing static contrast and HTTP checks does not establish theme behavior, layout correctness or complete accessibility.
- Packages were selected from compatible locally available releases, not a completed latest-patch/security audit. Review Next, Prisma and remaining package versions once registry access returns.
- No production credential, contact information or URL is invented. No default administrator is created.

## Important decisions

- Prisma 6.19.3 selected over Drizzle for available matching local CLI/client/engine. Review maintained-version upgrade after registry access is restored, before prompt 04.
- Maintained Better Auth is the intended integration, with compatible core schema and custom scrypt callbacks; no auth endpoint is exposed now.
- Protected routes deny everyone rather than simulating sessions. Future server queries/actions require their own authorization.
- Native form controls and a single Radix Dialog avoid a broad component dependency footprint.
- Indexing stays disabled even for a local production build. Local database and site origins are validated.
- CSP is a documented baseline with inline bootstrap allowances, not nonce-based protection. Upload policy/rate limiter are foundations, not verified end-to-end features.
